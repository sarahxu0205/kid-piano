# 🎵 小小钢琴 — 乡村儿童音乐启蒙

正如爱因斯坦所体会的，音乐与科学之间有着紧密联系。在他看来，音乐不仅仅是一种艺术形式，更是一种能够激发灵感和创造力的源泉。许多伟大的科学家都热爱音乐，这并非偶然。

这也是我做这个小小钢琴的初衷，希望乡村的孩子们也能有机会接触音乐、感受音乐，在他们心里种下一颗热爱的种子。

本项目面向乡村小学儿童和音乐教师，在音乐课堂中提供「网页虚拟钢琴 + 示范曲播放 + 轻松弹引导」的音乐学习体验，让没有钢琴的乡村孩子也能感受音乐的美好。

## ✨ 功能特性

### 🎹 虚拟钢琴

- 用电脑键盘就能弹奏
- 支持 3 个八度的音域
- 琴键上有唱名（do/re/mi）和字母（C/D/E）两种标注方式，可切换
- 底部有彩虹色条纹，好看又好认

### 🎵 示范曲库

- 内置 10 首经典儿歌和民谣
- 点击即可播放，琴键同步高亮
- 曲目轮播面板，方便选择

### 🎯 轻松弹引导

- 琴键闪烁提示下一个该按的键
- 琴键上方显示按键提示气泡
- 按对了才往下走，没有时间压力
- 弹完一首歌给三颗星的奖励

### 🎨 童趣设计

- 柔和天空渐变背景
- CSS 绘制的云朵、浮动音符、闪烁星星、小彩虹
- 药丸形按钮，适合孩子点击
- 响应式设计，适配各种屏幕

## 🚀 快速开始

### 直接运行

直接用浏览器打开 `index.html` 即可！

### 本地服务器（推荐）

如果你有 Python，可以运行：

```bash
# Python 3
python3 -m http.server 8000
```

然后在浏览器中访问 `http://localhost:8000`

## 🎮 使用说明

### 键盘映射

| 区域   | 白键                          | 黑键                  |
| ---- | --------------------------- | ------------------- |
| 低音区  | `Z` `X` `C` `V` `B` `N` `M` | `S` `D` `G` `H` `J` |
| 高音区  | `Q` `W` `E` `R` `T` `Y` `U` | `2` `3` `5` `6` `7` |
| 高音区+ | `I` `O` `P`                 | `9` `0`             |

### 操作说明

1. **开始弹奏**：点击「开始弹奏」按钮进入主界面
2. **弹奏**：用键盘上的按键或点击屏幕上的琴键
3. **切换八度**：点击工具栏上的 ◀/▶ 按钮，或用键盘的左右方向键
4. **切换标注**：点击「唱名」按钮，在唱名/字母/无标注之间切换
5. **听示范**：选择一首歌曲，点击「播放示范」
6. **轻松弹**：选择一首歌曲，点击「轻松弹」，跟着提示按键

## 🛠️ 技术栈

- **原生 HTML/CSS/JavaScript**：无需框架，简单易懂
- **Tone.js**：音频合成库，提供钢琴音色
- **PWA**：支持离线使用和添加到主屏幕
- **模块化设计**：代码结构清晰，易于扩展

## 💡 设计理念

做这个项目的初衷很简单：孩子的成长不止是学习文化课，素质教育同样重要。培养一个爱好，可以陪伴孩子一生。

音乐、美术、体育……这些看似"无用"的东西，其实有大用。它们能让孩子学会热爱生活，能在他们遇到挫折时提供慰藉，能成为他们一辈子的朋友。

希望这个小小的钢琴，能成为乡村孩子们音乐梦想的起点。哪怕他们未来不成为音乐家，哪怕只是偶尔弹一首喜欢的歌，这段音乐的体验也会在他们心里种下一颗热爱生活的种子。这就够了。
